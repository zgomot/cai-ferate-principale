# Căi ferate principale din România (sursă zgomot)

Acest proiect oferă o vizualizare web a căilor ferate principale din România, utilizate ca surse în evaluarea strategică a zgomotului conform Directivei 2002/49/CE.

## Vizualizare hartă

👉 https://zgomot.github.io/cai-ferate-principale/

## Tip serviciu

- Serviciu: WMS (Web Map Service)
- Standard: OGC WMS 1.1.1
- Sursă: GeoNoise MMAP

## Descriere

Layer-ul afișează căile ferate principale (MajorRailwaySource) care reprezintă sursele de zgomot pentru transportul feroviar.

Acest set de date NU reprezintă hărți de zgomot (contururi Lden/Lnight), ci infrastructura feroviară utilizată ca sursă pentru modelare.

## Instituție responsabilă

Ministerul Mediului, Apelor și Pădurilor (MMAP)

## Observații

Aceasta este o vizualizare web pentru explorarea datelor.

Pentru utilizare oficială și descărcarea datelor, utilizați serviciile INSPIRE (ATOM) sau fișierele publicate pe data.gov.ro.
